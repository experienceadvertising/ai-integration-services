Date: 2026-09-28. Public site: https://learncowork.net. Source: `experienceadvertising/ai-integration-services` on GitHub main plus Replit app `AI Integration Services`. This record follows the Zyppy SEO skill and shared cross-site techniques T01-T09, T13-T18, T21-T25, T28, T32, T45 and T47. Zyppy research guides prioritization; it does not prove a ranking outcome.

## Goal and evidence

The business goal is qualified bookings for practical AI training and workflow implementation. Search Console queries, conversions and provider index coverage were not available in this task. New page demand is an intent hypothesis from the existing training offer and adjacent page topics, not a measured query opportunity. Do not infer indexing, citations or lead lift from this release.

The live sitemap had 62 URLs at audit time. Direct HTTP inspection found that 41 sitemap URLs, mainly blog, glossary, role and free-tool pages, returned the homepage title and canonical in initial HTML. The correct article HTML was present at the `.html` URL. Replit's static artifact configuration had explicit rewrites for only part of the route set followed by a catch-all to `/index.html`. The current GitHub main includes an Express page-serving fix, but Replit serves the public site as a static artifact, so that Express handler does not fix the live routes. The Replit workspace was clean on a different local commit; it must be reconciled with GitHub before publication.

## Local acceptance checks

- Build prerenders the homepage plus 63 non-home public pages and emits client-only shells.
- `check-static-routes.mjs` requires both clean URL forms to point at each page's HTML, checks sitemap coverage and rejects a homepage catch-all.
- Audit generated HTML for one title, description, canonical and H1 per public page, unique titles, local OG image assets and working internal link destinations.
- Confirm the new guides' visible answers, vendor source links, related service links and usable booking path on desktop and mobile.
- Verify live status and initial HTML after release for all sitemap routes, plus a real 404 for an unknown URL and noindex for utility paths.
